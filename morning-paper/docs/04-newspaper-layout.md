# Движок вёрстки и система стилей

Это второй дифференциатор продукта (после персонализации). Газета должна **выглядеть как настоящая
газета**, а не как «страница из веба, сохранённая в PDF».

## Почему HTML/CSS + Paged.js + headless-браузер

Варианты рендера и почему выбран этот:

| Подход | Плюсы | Минусы | Вердикт |
|--------|-------|--------|---------|
| LaTeX | идеальная типографика | сложно динамически генерить, тяжело стилизовать «под газету», слабо с картинками/сетками | нет |
| InDesign + скрипты | дизайнерское качество | проприетарно, не серверный пайплайн | нет |
| Прямая генерация PDF (ReportLab и т.п.) | контроль | вёрстку колонок/переносов писать руками — дорого | нет |
| **HTML/CSS + Paged.js → Chromium → PDF** | веб-вёрстка, легко темизировать, готовые колонки/`@page`, картинки, шрифты | нужен headless-браузер | **да** |

**Paged.js** — полифилл стандарта CSS Paged Media: даёт постраничную разбивку, колонтитулы,
номера страниц, контроль висячих строк, многоколоночность, «продолжение на стр. N». Рендерим в
**Chromium через Playwright** → print-ready PDF.

## Анатомия страницы газеты

```
┌───────────────────────────────────────────────┐
│  MASTHEAD (название издания, дата, выпуск)      │  ← SVG/типографика темы
├───────────────────────────────────────────────┤
│  ПЕРЕДОВИЦА (lead): крупный заголовок,           │
│  фото, 2–3 колонки текста, врезка с цитатой      │
├──────────────────┬────────────────────────────┤
│  Колонка слева   │   Колонка справа             │
│  заметка + фото  │   заметка                    │
├──────────────────┴────────────────────────────┤
│  СЕКЦИЯ «Мир» · «Технологии» · «Бизнес» · ...    │
│  набор заметок разного размера (иерархия)        │
├───────────────────────────────────────────────┤
│  колонтитул: издание · стр. N · дата             │
└───────────────────────────────────────────────┘
```

Редакторская сборка (стадия 6 пайплайна) решает: что на передовицу, какие секции, какой размер у
каждой заметки (lead / средняя / бриф), где врезки и фото. Это сама по себе LLM-задача с
ограничениями («заполни сетку», «не более 1 передовицы», «баланс секций»).

## Система тем (styles)

Тема = декларативный набор параметров, накладываемый на одну и ту же структуру контента. Чтобы
добавить новый стиль, не трогаем пайплайн — только тему.

Тема описывается как набор CSS-переменных + ассеты:

```css
/* пример: тема "The Times" — классический broadsheet */
:root[data-theme="times-classic"] {
  --masthead-font: "Old English Text MT", "UnifrakturCook", serif;
  --headline-font: "Georgia", "Times New Roman", serif;
  --body-font: "Times New Roman", Georgia, serif;
  --accent: #000000;
  --paper: #f7f4ec;          /* кремовая бумага */
  --rule-weight: 1px;        /* тонкие линейки между колонками */
  --columns: 6;              /* плотная многоколоночная сетка */
  --color-mode: bw;          /* чёрно-белая */
}
```

Стартовый набор тем:

| Тема | Настроение | Ключевые черты |
|------|------------|----------------|
| `times-classic` | классический broadsheet | плотные 6 колонок, ч/б, готическая шапка, засечки |
| `economist` | строгий деловой | красная шапка, чёткая сетка, смесь serif/sans, инфографика |
| `nyt-modern` | современный качественный | крупная типографика, воздух, серифный заголовок |
| `mono-minimal` | чёрно-белый минимализм | без фото или дуотон, акцент на типографике |
| `vintage` | ретро 1920-х | состаренная бумага, орнаменты, винтажные шрифты |

Каждая тема хранит: переменные сетки/цвета/шрифты, SVG-шапку, правила для фото (ч/б, дуотон, цвет),
правила переносов и микротипографики.

## Форматы страницы

`@page` управляет физическим размером — пользователь выбирает под свой принтер/вкус:

- **A4 / Letter** — печать на домашнем принтере (по умолчанию).
- **A3** — разворот, ближе к ощущению газеты.
- **Broadsheet (11"×22") / Tabloid (11"×17")** — для печати по требованию в типографии.

## Print-ready нюансы

- Поля/без полей, метки реза (bleed) — для POD-типографий (например, Newspaper Club / MakeMyNewspaper
  требуют запас ~0.5").
- Цветовой режим: домашняя печать — RGB; типография — обычно CMYK, чёрный текст — чистый чёрный.
- Встраивание шрифтов в PDF; растеризация только там, где нужно.
- Картинки: ресайз/сжатие, опц. перевод в ч/б или дуотон под тему.

## Расширяемость

Темы — это контент, а не код. Логичный путь развития (фаза 3): редактор тем / маркетплейс шаблонов,
где можно собрать свой стиль из переменных и шрифтов без программирования.
