# Технический стек, модели и стоимость

Конкретные технологии с обоснованием. Принцип: брать зрелое и быстрое в разработке, не изобретать.

## Стек по слоям

| Слой | Выбор | Почему |
|------|-------|--------|
| Backend / API | **Python + FastAPI** | экосистема data/AI, быстрый старт, async |
| Воркеры / очередь | **Celery + Redis** (или Temporal на v1) | надёжные ночные джобы; Temporal — если нужны сложные ретраи/состояния |
| Расписание | Celery beat / cron | запуск выпуска в 05:00 по TZ пользователя |
| Хранилище | **Postgres + pgvector** | профили, статьи, эмбеддинги в одном месте; vector search без отдельной БД |
| Объекты | **S3-совместимое** (S3 / R2 / MinIO) | PDF, картинки |
| Telegram-ин | **Telethon** (MTProto, user-аккаунт) | чтение каналов/чатов от лица пользователя |
| Instagram-ин | Graph API / экспорт данных | официальный путь ограничен — берём что можно (фаза 2) |
| RSS / почта | `feedparser` + входящий SMTP | rss и рассылки |
| Новостные API | **GDELT** (бесплатный, мультиязычный) + **NewsAPI** | широкий многоязычный охват кандидатов |
| Эмбеддинги | **Voyage AI** (мультиязычный, напр. `voyage-3.5`) | у Anthropic нет embeddings; Voyage — рекомендованный, кладёт языки в одно пространство |
| LLM | **Claude API** (раскладка ниже) | суммаризация, перевод, заголовки, редактура, сборка сетки |
| Вёрстка | **HTML/CSS + Paged.js + Playwright/Chromium** | газетная типографика → print-ready PDF (см. 04) |
| Доставка | **Telegram Bot API** + email (Resend/SES) | PDF + ссылка |
| Веб/кабинет | **Next.js** | веб-версия газеты, онбординг, настройки |
| Печать (v3) | **Newspaper Club / Mixam API** | физическая газета по требованию |

## Раскладка моделей Claude по задачам

Цены — за 1M токенов (вход / выход), июнь 2026:

| Задача | Модель | Цена (вход/выход за 1M) | Почему |
|--------|--------|--------------------------|--------|
| Тегирование сигналов, классификация тем | **Claude Haiku 4.5** (`claude-haiku-4-5`) | $1 / $5 | дёшево и быстро на больших объёмах |
| Суммаризация + перевод заметок (массово) | **Claude Sonnet 4.6** (`claude-sonnet-4-6`) | $3 / $15 | лучший баланс цена/качество для объёма |
| Передовица, редакторская сборка сетки, тонкие заголовки | **Claude Opus 4.8** (`claude-opus-4-8`) | $5 / $25 | качество там, где оно видно читателю |
| Особо сложная авто-редактура / агентный режим (опц.) | **Claude Fable 5** (`claude-fable-5`) | $10 / $50 | самый сильный; только если реально нужен |

> Все ID — точные строки, без суффиксов дат. Для нового AI-кода по умолчанию — последние модели.

### Как сильно экономим на ночном прогоне

Выпуск газеты **не требует низкой задержки** (готовим ночью к утру), поэтому:

- **Batch API (−50% к цене)** — тегирование и массовая суммаризация идут пачкой. Большинство батчей
  завершаются в пределах часа — для ночного окна идеально.
- **Prompt caching (до −90% на кэш-чтении)** — общие части промптов стабильны от выпуска к выпуску и
  между пользователями: системный промпт «стиль издания», правила вёрстки/сборки сетки, таксономия
  тем, гайдлайны перевода. Кэшируем префикс → платим полную цену один раз, дальше кэш-чтение.
- **Структурированный вывод** (`output_config.format`) для тегов/сущностей и плана сетки — валидный
  JSON без парсинга «на глаз».
- **Адаптивное мышление** (`thinking: {type: "adaptive"}`) для редакторских задач (сборка сетки,
  передовица); для дешёвого тегирования — без него.

## Прикидка стоимости одного выпуска (очень грубо)

Допущения: ~300 кандидатов в день → тегирование/эмбеддинг; ~30 финальных заметок → суммаризация +
перевод; ~5 «крупных» материалов через Opus; общие промпты закэшированы; массовое — через Batch.

| Статья | Оценка |
|--------|--------|
| Эмбеддинги (Voyage) ~300 коротких текстов | центы |
| Тегирование 300 шт (Haiku, Batch, кэш) | ~$0.01–0.05 |
| Суммаризация+перевод 30 заметок (Sonnet, Batch, кэш) | ~$0.05–0.20 |
| 5 крупных + сборка сетки (Opus, кэш) | ~$0.05–0.15 |
| Рендер PDF (Playwright) | стоимость CPU, копейки |
| **Итого на 1 выпуск 1 пользователя** | **≈ $0.10–0.50** |

Порядок величины: десятки центов за выпуск. Это закрывается подписочной ценой ($5–15/мес) с большим
запасом и даёт пространство для премиум-уровней (печать, ежедневный Opus, больше источников).

> Цифры ориентировочные — перед запуском перепроверить реальным прогоном на `count_tokens` и
> измерением на своих промптах; не закладывать как точные.

## Минимальный технологический риск

- Газетная вёрстка через Paged.js — главный технический риск (надо довести до «выглядит как газета»).
  Поэтому в плане она вынесена в **Фазу 0** — проверяем раньше всего.
- Telegram-парсинг — продуктовый/юридический риск (ToS, лимиты). Решение — действовать от лица
  пользователя, не масштабировать один аккаунт.
