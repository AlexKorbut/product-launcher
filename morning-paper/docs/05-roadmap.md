# План реализации

Принцип: каждая фаза заканчивается чем-то, что можно показать и пощупать. Сначала добиваем самый
рискованный кусок (газетная вёрстка), потом наращиваем персонализацию и каналы.

## Фаза 0 — прототип вёрстки (1–2 недели)

**Цель:** доказать, что мы умеем делать PDF, который выглядит как настоящая газета. Без
персонализации, без Telegram.

- [ ] Один источник: 1–2 RSS-ленты (например, мировые новости).
- [ ] Простой отбор: Claude выбирает ~15 заметок и пишет короткие пересказы + заголовки.
- [ ] Один шаблон темы (`times-classic`) на HTML/CSS + Paged.js.
- [ ] Рендер в PDF через Playwright, формат A4.
- [ ] Артефакт: `issue.pdf`, который реально приятно распечатать.

**Критерий успеха:** распечатанный PDF неотличим по ощущению от газетной полосы.

## Фаза 1 — MVP (4–6 недель)

**Цель:** работающая персональная газета для себя и 5–10 первых пользователей.

- [ ] **Telegram-импорт** (Telethon): подключение аккаунта, чтение каналов + пересланного/реакций.
- [ ] **Профиль интересов**: тегирование (Haiku), эмбеддинги (Voyage), темы+сущности+вектор в Postgres/pgvector.
- [ ] **Многоязычный отбор**: кандидаты из GDELT/RSS + Telegram → ранжирование по профилю + дедуп.
- [ ] **Суммаризация + перевод** на язык пользователя (Sonnet, Batch API, prompt caching).
- [ ] **Редакторская сборка** + **2–3 стиля** (`times-classic`, `economist`, `mono-minimal`).
- [ ] **Расписание** (05:00 в TZ юзера) + **доставка в Telegram-бота** (PDF + веб-ссылка).
- [ ] Базовый онбординг через бота: выбор языка, тем, стиля, формата.

**Критерий успеха:** каждое утро автоматически приходит релевантная газета в выбранном стиле.

## Фаза 2 — v1 (2–3 месяца)

**Цель:** продукт, который можно давать незнакомым людям.

- [ ] **Личный кабинет (Next.js)**: настройки, источники, темы, превью стилей, история выпусков.
- [ ] **Обратная связь**: 👍/👎 по заметкам и секциям, «больше/меньше такого» → дообучение профиля.
- [ ] **Instagram-коннектор** (что официально доступно).
- [ ] **Больше стилей** (`nyt-modern`, `vintage`) + выбор формата A3/Letter.
- [ ] **Веб-версия газеты** (адаптивный HTML того же контента).
- [ ] **Аудиоверсия (TTS)** — «послушать газету» за кофе/в дороге.
- [ ] Приватность: тумблер личных чатов, экспорт/удаление данных (GDPR/CCPA).
- [ ] Наблюдаемость: метрики стоимости на выпуск, качество отбора, дочитываемость.

**Критерий успеха:** новый пользователь за 5 минут онбординга получает свою газету; качество растёт
от обратной связи.

## Фаза 3 — v2 (после product-market fit)

- [ ] **Печать по требованию**: интеграция с типографией (Newspaper Club / Mixam), доставка бумаги.
- [ ] **Семейные/командные подписки**: общая газета на несколько человек.
- [ ] **Редактор тем / маркетплейс шаблонов**: свой стиль без кода.
- [ ] **Тонкая настройка выпуска**: расписание (будни/выходные), длина, секции, «дайджест недели».
- [ ] Возможный агентный режим на Claude Fable 5 для сложной авторедактуры/ресёрча.

## Сразу решить (не откладывать)

1. **Юридика Telegram/СМИ.** Парсинг от лица пользователя + дайджест-формат со ссылками на оригинал.
   Зафиксировать с юристом до публичного запуска (см. предупреждение в [02-architecture.md](02-architecture.md)).
2. **Приватность личных чатов.** Дефолт — минимум хранения сырого текста + тумблер отключения.
3. **Стоимость.** Перепроверить прикидку из [06-tech-stack.md](06-tech-stack.md) реальным прогоном
   до того, как обещать цену подписки.

## Первый шаг прямо сейчас

Начать с **Фазы 0**: собрать скелет `RSS → отбор Claude → шаблон `times-classic` → PDF`. Это
снимает главный технический риск (вёрстка) и даёт осязаемый артефакт, вокруг которого удобно строить
всё остальное.
