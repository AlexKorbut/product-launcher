# 07 — Экономика и монетизация

Этот документ фиксирует, **сколько стоит выпуск**, **на чём зарабатываем** и **как это
проверять**. Технически опирается на слой учёта стоимости (`economics.py`, `metering.py`,
таблица `usage_events`) и команды `morning-paper estimate` / `morning-paper cost`.

## 1. Себестоимость выпуска (COGS)

Основная переменная статья — вызовы Claude. Маршрутизация по моделям (`config/settings.toml`):

| Задача | Модель | Цена (in/out за 1М токенов) |
|---|---|---|
| Тегирование сигналов, классификация | Haiku 4.5 | $1 / $5 |
| Суммаризация + перевод (массово) | Sonnet 4.6 | $3 / $15 |
| Передовица, сборка сетки, заголовки | Opus 4.8 | $5 / $25 |

Удешевление (учтено в `economics.cost_of`):
- **Batch API −50%** — тегирование и массовая суммаризация идут пачкой (ночное окно это позволяет).
- **Prompt caching −90% на кэш-чтении** — стабильные префиксы (стиль издания, правила вёрстки,
  таксономия, гайд перевода) кэшируются один раз и переиспользуются между выпусками и пользователями.
- **Рендер PDF (Playwright/Chromium)** — это инфраструктурная стоимость CPU (копейки), не токены.

**Ориентир: $0.10–0.50 на выпуск на пользователя.** Это **оценка**, которую обязательно
перепроверяем реальным прогоном (`cli cost --issue <id>`) до обещаний цены подписки. Эмбеддинги
(Voyage, ~300 коротких текстов) — центы.

## 2. Юнит-экономика → рычаг цены = частота

- Ежедневный выпуск ≈ 30 × ~$0.15 ≈ **~$4.5/мес** COGS.
- Еженедельный ≈ 4 × ~$0.15 ≈ **~$0.6/мес** COGS.

Отсюда тарифы строятся вокруг **частоты, числа стилей и числа источников**, а не «фич ради фич».

## 3. Тарифы (freemium B2C)

| План | Цена | Частота | Стили | Источники | Доставка |
|---|---|---|---|---|---|
| **Free** | $0 | еженедельно | 1 | manual + RSS | веб / вотермарк |
| **Plus** | ~$8/мес | ежедневно | все 8 | + Telegram/Instagram | PDF, email, бот |
| **Pro** | ~$18/мес | ежедневно | все 8 | все | + несколько изданий/профилей, Opus-редактура, приоритет, скидка на печать |
| **BYOK** | платформенная плата | как Plus/Pro | все | все | пользователь приносит свой `ANTHROPIC_API_KEY` → наш COGS ≈ 0 |

Маржа: при COGS ~$4.5/мес ежедневный Plus за ~$8 уже прибылен; еженедельный Free почти бесплатен
для нас и работает как воронка. Pro даёт пространство для дорогих опций (Opus каждый день, печать).

## 4. B2B / white-label («Newspaper-as-a-Service») — высший потолок выручки

Тех. основа уже закладывается эндпоинтом `POST /v1/render` (stateless: JSON → свёрстанный PDF).

- **Render-API** — отдаёшь контент (`RenderDocument`), получаешь print-ready PDF в наших стилях.
  Тарификация per-render или подпиской. Покупатели: рассылки, медиа, генераторы отчётов.
- **API персонализации/дайджеста** — профиль интересов + отбор + пересказ как сервис для СМИ.
- **White-label** — отели (утренняя газета в номер), авиакомпании (лаунж/борт), корпоративные
  утренние брифинги. Per-seat / per-issue лицензия, свой masthead и темы.

Учёт стоимости (`usage_events`, `issue_cost`) — основа биллинга: каждая единица (issue / render)
несёт свою себестоимость, поверх которой ставится наценка.

## 5. Печать по требованию + подарки (премиум-ARPU)

Наш физический дифференциатор. Интеграция с типографией (Newspaper Club / Mixam): реальная
бумажная газета почтой. Подарочные и спецвыпуски (свадьба, «итоги года», именная первая полоса) —
высокая готовность платить, эмоциональный продукт.

## 6. Маркетплейс стилей (долгий хвост)

Темы — это **данные** (`themes/<id>/` + entry-points), сторонние темы добавляются без правок кода.
Дизайнеры публикуют премиум-стили, мы берём комиссию.

## 7. Чего НЕ делаем (ограничение приватности)

Продажа пользовательских данных и таргетинг на основе личных переписок — **исключены**: это
противоречит нашим обязательствам (`docs/03`: сырой текст личных чатов не хранится, `is_private`,
экспорт/удаление по GDPR/CCPA). Допустим максимум **opt-in** спонсорский блок, не на приватных данных.

## 8. Как проверяем экономику (инструменты)

```bash
# Грубая оценка без ключа (чистый Python):
morning-paper estimate --signals 300 --stories 30        # ждём ~$0.10–0.50

# Фактическая стоимость по реальному прогону (нужен ANTHROPIC_API_KEY):
morning-paper init-db
morning-paper run-issue --user me
morning-paper cost --issue <issue-id>                    # сумма + разбивка по стадиям/моделям
morning-paper cost --user me --since 2026-06-01          # агрегат по пользователю
```

Каждый вызов Claude пишет фактические токены (`response.usage`, включая кэш-чтения) и посчитанную
стоимость в `usage_events`; `issue_cost`/`user_usage` агрегируют. Это позволяет: (1) подтвердить
ценовую модель цифрами, (2) позже включить квоты/лимиты тарифов по `user_usage`.
